# 我能打职业

《我能打职业》是一款中文横屏篮球战术与球员生涯模拟游戏，当前以“玩家娱乐版（非官方预发布原型）”形式由项目作者维护。

> 本仓库已经包含可审查的开发版源码，但它不是开源项目、公开公测、正式发行版或商业产品。项目仅用于个人娱乐、篮球战术交互研究、产品讨论与技术演示。除非另有可核验的书面说明，本项目与任何职业篮球联盟、球队、球员、经纪机构、体育品牌、设备品牌或其他商业游戏厂商均无隶属、授权、赞助、背书或联名关系。“玩家娱乐版”“非官方”“非商业”或其他免责声明不能替代第三方许可。

## 当前源码范围

- 创建球员：五个位置、30 种打法模板、38 项能力、循环球衣号码选择。
- 教学与生涯入口：UMich 对 UCoon 的末节教学、一次性首年选秀或直接选队。
- 比赛核心：十人动态战术板、持球/无球/防守五键、挡拆、突分、快攻、传球飞行、投篮、篮板、犯规、自动罚球、出界发球、8/14/24 秒与回场等状态机。
- 生涯框架：日历、训练、属性购买、常规赛模拟、附加赛、七场四胜季后赛、个人统计、年龄增长、32 岁后衰退、40 岁强制退役和最多 20 赛季循环。
- 移动体验：iPhone 与 Pixel 10 横屏预览、手机横屏全视口、安全区、竖屏暂停保护、中文错误恢复页和本地音频状态控制。

当前运行数据以合成球员为主，不包含官方 Logo、官方球衣图案或竞品专有属性表。详细完成范围与已知限制见 [公测范围与上线边界](docs/release/PUBLIC_BETA_SCOPE.md)及[发布阻塞项矩阵](docs/release/RELEASE_BLOCKERS.md)。

## 本地检查与运行

项目锁定 Node.js `24.14.1`。以下命令仅供获得项目作者授权的维护者和测试者使用；仓库公开可见本身不构成构建、部署或再分发许可。

```powershell
npm ci
npm run check:release
npm run dev -- --host 127.0.0.1 --port 4173
```

浏览器访问 `http://127.0.0.1:4173/`。完整门禁还包括 `npm audit --audit-level=high`；`npm run check:release:public` 是严格公开发行门禁，当前会因权利台账中的开发期条目而失败。该失败被保留用于阻止把本源码误标为发行就绪版本。
