# 战术棋子交互研究与本轮落地

日期：2026-09-01

## 1. 采用的篮球原则

- 固定的是进攻原则，不是整段动画。一个战术从落位和发起开始，随后应根据防守阅读进入顺下、外弹、急停、短顺下、弱侧转移或重新组织。
- 空间、球员移动、球转移和防守阅读必须同时存在；机械照路线跑完不能算真实战术执行。
- 挡拆面对绕下、追防、沉退、延误/夹击和换防时应给出不同反制；无球掩护则读取直切、卷切、外切和后门。
- 转换进攻以宽边推进、中路跟进和拖曳挡拆衔接阵地，不在快攻窗口结束时瞬移重置。

主要官方参考：

- [FIBA/WABC Level 1 教练手册](https://assets.fiba.basketball/image/upload/documents-corporate-wabc-coaching-level-manuals-level-1-eng.pdf)：空间、挡拆持球/掩护人阅读、无球掩护切法和突破接应。
- [FIBA/WABC Level 3 教练手册](https://assets.fiba.basketball/image/upload/documents-corporate-wabc-coaching-manual-level-3-eng.pdf)：高阶连续掩护、screen-the-screener 与对联防空间。
- [FIBA/WABC 教练课程目录](https://about.fiba.basketball/en/wabc-videos)：进攻空间、后卫决策、无球掩护和五外读防主题。
- [NCAA 男篮规则资源](https://www.ncaa.org/championships/playing-rules/mens-basketball-playing-rules/)：教学局规则框架核对；不作为战术路线来源。

## 2. 本轮产品决策

- 玩家四套战术采用 `家族 + 上下侧 + 3种语义分支 + 主参与者` 的完整签名。
- 相邻签名不重复；最近3个签名进入排除集合，同一家族仍可通过换侧或换阅读继续使用。
- 阶段显示为落位、发起、阅读、反制，进度直接从真实24秒经过时间派生，不增加第二套计时器。
- 棋子显示战术角色，但最多突出持球者与两名关键参与者；路线只画当前剩余节点，主路线更粗，避免线网遮住场地。
- 战术执行分读取全队篮球智商、无球移动、决策、传球视野与准确；未到位时提前终结为轻微负修正，到位后的正负修正绝对值封顶3个百分点。
- 电脑半场回合采用战术ID硬去重和完整路线签名去重两层规则。转换战术池当前只有一类，因此快攻不承诺战术ID轮换，后续需增加提前传球和拖车挡拆两套转换家族。

## 3. 后续动态读防升级

当前玩家语义分支在战术呼叫时确定。下一阶段改为：入口与发起先确定，在掩护接触或传球窗口形成时，根据实际对位距离、防守覆盖和弱侧协防动态选择反制；玩家篮球智商只决定提示时机与窗口宽度，不替玩家自动完成正确动作。
