# 2026 首轮选秀数据来源

- 核对日期：2026-09-02。
- 官方选秀板：https://api-hub-dev.nba.com/draft/2026/draft-board
- 导入范围：首轮第 1–30 顺位的选队、英文新秀名，以及官方页面列出的签位后续去向。
- 游戏仪式以“执行选择的球队”展示每个固定签位；若页面记录了后续交易，则另行显示“该签位随后交易至……”提示。
- 自创球员插入其评估顺位，现实候选人从该位置开始整体顺延一位，首轮仍只保留 30 人。球队签位顺序不因自创球员插入而改变。

运行时数据位于 `src/game/draft-2026.ts`。更新数据时必须同时核对 30 个唯一签位、前三顺序、自创球员插入和末位截断测试。
