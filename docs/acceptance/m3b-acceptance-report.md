## 2. 关键守恒检查

- 罚球阶段比赛钟与进攻时间不流逝；五个比赛按钮全部锁定并提示无需操作。
- 投篮命中加罚时，运动战得分先结算一次，罚球只增加罚球得分。
- 最后一罚未中在篮板控制前不提前翻转球权或记篮板。
- 防守干扰球不同时记盖帽；进攻干扰球不保留原投篮命中。
- 十个球员 ID 唯一，主客各五人；个人得分合计与初始比分后的球队得分增量相等，正负值全场求和为零。
- 第六次个人犯规不会抹除此前统计，但当前只登记犯满，尚无替补换人。
- 自然个人犯规的滑动10回合窗口跨玩家与电脑共同计算；自然三分投篮犯规还受滑动50回合窗口约束。两个阈值都是上限，不保证窗口内必有犯规。
- 进攻篮板、防守碰球出界续权和普通犯规续权不创建新的频率回合；强制判罚和QA入口不会被自然概率门误拦截。
- 创建球员在当前场上十人模型中保持登场；这是一条产品不变量，不代表替补和轮换系统已经完成。

## 4. 保留缺口

以下未计入本次“通过”口径：替补席与非创建球员轮换、犯满后的替补流程、球队暂停次数、教练挑战、争球、回场、全部罚球违例，以及玩家主动触碰空中篮球或自由争抢空中球。创建球员保持登场已经冻结为产品约束，但当前仍没有轮换引擎。争抢犯规已有可调用规则类型，但尚未从自然篮板对抗自动产生，仍需后续接线与验收。
