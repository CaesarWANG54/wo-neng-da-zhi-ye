# M7B 真实赛程手打与结算验收

日期：2026-09-02
范围：日历下一场赛程、正式四节比赛、赛果/统计/金币/默契结算与返回日历。

## 已验收契约

- 开赛前按时间顺序模拟此前联盟赛程并逐周结算训练；只保留所选下一场为 `SCHEDULED`。
- 正式生涯赛从0:0、第1节开始；8/12/24分钟总时长分别使用120/180/360秒每节和50/75/150秒加时。
- 开赛快照冻结难度、时长和有效能力；暂停中修改设置不能改写本场奖励。
- 终场用真实赛程ID原子写入主客场比分、两队战绩、创建球员累计统计、金币和胜负默契。
- 奖励事件与默契事件均从赛程ID派生；重复点击、重复调用或刷新不会重复入账。
- 模拟已结束、未完成、平局、非法投篮统计、错误日期或陈旧对手契约均拒绝奖励。
- 赛季最后一场被留给玩家时不提前评奖；该场合法结算后才生成首年奖项。
- iPhone 13与iPhone 15 Pro横屏覆盖开赛确认、完整比赛界面、终场弹窗和返回日历，主操作按钮不小于44px且无溢出。

## 缺陷收口

- 客场比赛统一使用“我方/对方”球权语义，不再把内部受控方误称为真实主队。
- 杯赛未解析时会阻断12月12日后的已知赛程；玩家先显式确定12月5日、9日对阵，再选择手打或模拟。
- 根存档拒绝单边、未知、未结束或非玩家队赛程的结算标记。
- 根存档写入失败时保留终场弹窗和赛前档案，恢复存储后可安全重试；不会先返回日历再丢失结果。

## 明确边界

- 活跃比赛中途状态不持久化；刷新会放弃未完成对局并回到当天可再次开赛，不产生奖励。
- 当前仍是合成场上十人；替补轮换、真人阵容包、附加赛、七场系列赛和跨赛季年龄/退役属于后续里程碑。
