## 3. 阻断级边界证据

- 24秒与比赛钟同时归零时，节末优先，不额外记违例。
- 24秒、8秒与5秒违例均只产生一个事件，时钟不会进入负数。
- 防守碰出保留球权与剩余进攻时间；进攻碰出翻转球权并记失误；触筐后防守碰出重置14秒。
- 普通死球冻结两钟；进球后是否继续比赛钟按节次和末段停表规则决定。
- 进球流程的得分和球权变化只发生在语义结算时；后续动画只改变阶段。
- 自动阶段使用 `phaseToken` 防止旧回调推进新回合；普通计时帧不改变 `decisionEpoch`，不会破坏260ms单/双击仲裁。
- 终场后推进10秒并尝试比赛动作，比分、统计、事件和时钟均保持不变。
- 普通第2–4节按开场球权规则从底线发球，只有加时执行中圈跳球；换防对位在死球和球权转换时恢复基础落位。

## 6. 签收

M3A 冻结计划中的全部分任务已经落地并与验收证据逐项对齐。当前版本可以从活球连续运行到死球、发球、推进、阵地、快攻、普通节间发球、加时跳球或终场，所有终态都能进入下一合法状态或保持最终冻结，可作为后续犯规/罚球和完整赛季系统的稳定底座。5秒发球与8秒后场违例目前在自动界面流程中通常会被更早的自动动作避开，主要作为规则引擎保护分支；玩家发球决策和真实延误归 M3B/M4。
