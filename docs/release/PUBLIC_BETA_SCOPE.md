## 1. 当前状态：受保护的 Public 开发源码

所有者已创建 Public 仓库、选择玩家娱乐版专有非开源许可，并明确要求加入开发版游戏源码。公开可见不授予进一步使用权，也不等于公开 Web 公测或应用商店版本。权利台账中的开发期状态没有因源码上传而升级；严格公开门禁继续阻止发行候选与部署。

- 真实计时、24/14/8秒、回场、出界/发球、快攻/阵地、固定释放落点传球、投篮/篮板、低频犯规、自动罚球、三秒和干扰球等当前规则闭环。

## 2. 公开 Web 公测：额外阻塞

公开链接、公开GitHub源码或任何无需邀请即可访问的构建，必须在私有预览条件之外关闭以下项目：

- 仓库所有者已改用“《我能打职业》项目作者”中性署名与玩家娱乐版专有`LICENSE`，明确Public只代表公开可见而非开源；仍需由项目授权负责人或专业人士复核原创权属链、第三方许可和文本。
- 构建中每一项内容达到适用范围的`APPROVED_RELEASE`，或在公开包中移除/替换：球队简称/颜色、模板人物参照、选秀与赛程事实数据、设备预览素材、参考图、CC0音频、Roboto与Phosphor等第三方内容。
- `npm run check:release:public`通过；最终第三方 notices、资产/音频清单与实际构建完全一致。
- 在真实HTTPS托管域名复核CSP、`nosniff`、Referrer/Permissions Policy、同源隔离、防嵌入、缓存和HSTS；不能只引用本地Worker测试。
- 首次云端CI、依赖审计、secret scanning、Dependabot和私密漏洞报告设置完成；不得虚构安全邮箱。
- 完成面向公开用户的隐私说明、反馈渠道、版本/已知问题页、回滚提交和事故响应责任人。
- 若公开Web公测明确支持手机，则实体iPhone Safari、安全区、音频解锁、后台/锁屏、VoiceOver和长局稳定性同样是发布门禁。

## 3. 真人阵容内容版：独立数据/权利门

真人阵容不是当前合成Web预览的隐含下一步，必须作为独立内容包验收：

1. 锁定名单冻结日、允许显示的中文名/称号、30队身份和架空交易覆盖版本。
2. 每名真人的38项数值必须来自明确获准的数据源或可审计的独立推演模型，保存字段级来源、日期、置信度、人工调整和审核人。
3. 不复制、轻微扰动或批量转竞品逐项数值；联盟/球队/球员许可不能自动覆盖竞品数据库权利。
4. 在进入发行构建前完成异常分布、历史表现、同位置分位、伤病/小样本与单次大幅变化复核。
5. 真人内容的名称、数据、平台、地区、期限、营销和离线再分发范围均取得可审计签核；未批准时构建自动回退到合成阵容。

## 4. 移动应用 / TestFlight：独立工程门

即使公开Web版本已通过，移动安装包仍需额外完成：

- 真机链路：实体iPhone Safari和目标机型完成横竖屏切换、安全区、双击、音频首次解锁、来电/锁屏/后台恢复及连续30分钟运行记录。
- 实现并验收**真正的活跃比赛中途恢复**，包括比赛阶段、两钟、球权、随机状态、十人位置、飞行、统计与待决输入；启动/错误兜底不能替代这一功能。
- 完成Capacitor或等价容器、横屏策略、原生生命周期、离线资产、权限最小化、隐私清单、签名、版本号和商店审核材料。
- 完成VoiceOver、键盘/焦点（外接设备）、对比度、动态文字、减少动态效果和触控目标验收。
- 记录冷启动、主线程卡顿、内存、CPU、发热、耗电、客户端总量、最大JS/CSS块和最长生涯存档；超预算时先优化再签名。
- 证书、描述文件、API密钥和许可合同只进入受限发布系统，不进入Git仓库或客户端。
