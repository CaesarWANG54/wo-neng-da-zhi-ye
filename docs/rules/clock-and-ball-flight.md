# 计时、发球与篮球飞行模型

版本日期：2026-09-01。本文只记录当前原型已经落地的计时与球权语义，以及为手机战术板采用的可解释运动学近似；不宣称已经覆盖职业篮球规则的全部执法细节。投篮、篮板和转换的扩展映射见 [rebound-and-transition.md](rebound-and-transition.md)。

## 规则依据与当前边界

- 一次新球权从 24 秒开始。合法发球触球后，比赛钟、进攻时间与后场 8 秒在同一个 `advanceMatchTime` 权威循环中推进。
- 后场推进不靠固定动画时长自动结束。主队持球点或客队持球点实际越过中线后才提交 `FRONTCOURT`；否则后场 8 秒归零时判违例。
- 普通防守碰球出界且原进攻方保留球权时，保留未使用的进攻时间，不能统一把 3 秒回到 14 秒。
- 只有带有对应规则原因的前场重启才应用 14 秒。本版已经区分触圈后原进攻方控制/保有球权的 14 秒路径，与普通防守碰出界的保留剩余时间路径。
- 出手在比赛钟或进攻时间到零前离手后，`SHOT_FLIGHT` 会完成该次合法投篮。命中可在钟响后计分；投失则该节结束，不继续生成跨节篮板争抢。
- 触圈投失后进入 `REBOUND`，在任何球员建立控制前不把球权提前判给一方。进攻篮板控制瞬间设为 14 秒；防守篮板控制瞬间建立新球权并设为 24 秒。
- 犯规触发的自动罚球使用独立 `FREE_THROW` 状态。落位、罚球飞行与每罚间隔期间比赛钟和进攻时间均冻结；最后一罚触圈未中才重新进入普通 `REBOUND`，技术罚球则按判罚保留原进攻方前场球权。
- 空气球或被封盖后形成的未触圈活球不会自动回 14 秒。原进攻方追回时保留已经流逝的进攻时间；防守方建立控制时才成为新球权。
- 死球、发球准备、节间和终场会原子清除不兼容的路线、速度、电脑决策与篮球飞行。

## 球场尺度与三维表现

战术板地面坐标仍是 `0–100` 的百分比，但移动与球速不使用屏幕像素作为物理距离。分别按以下尺寸换算：

```text
x米 = x百分比 / 100 × 28.65
y米 = y百分比 / 100 × 15.24
距离 = hypot(Δx米, Δy米)
```

28.65 米 × 15.24 米对应 94 英尺 × 50 英尺的场地比例；篮圈上沿高度为 3.05 米。官方场地与器材规则：<https://official.nba.com/rule-no-1-court-dimensions-equipment/>。

篮球只有一个权威飞行对象，但同时记录三个相互独立的展示维度：

```text
地面投影：x / y
物理高度：z = startHeight、endHeight、apexHeight 与归一化时间的解析函数
地面阴影：仅跟随 x / y，并按 z 调整尺度和透明度
```

投篮不能再用“向屏幕上方移动 y”冒充升高。`PASS`、`LOB`、`HANDOFF`、`INBOUND`、`OUTLET`、`SHOT`、`FREE_THROW`、`RIM_REBOUND` 与 `LOOSE_BALL` 都通过同一个 `BallFlightState` 推进；界面持续显示篮球及当前高度。

## 传球、投篮与反弹飞行

每次成功传球创建唯一飞行状态，记录起点、接球人、释放瞬间固定的接球落点、米制距离、速度、总时长、已飞行时间和高度参数。规则层在动作开始时按固定种子一次性决定结果；视觉轨迹不会再次抽签或改变结果。

```text
普通传球速度 = 7.6 + 4.8 × clamp(传球速度属性, 25, 99) / 99  米/秒
空接速度 = 普通传球速度 × 0.70
发球速度 = 普通传球速度 × 0.88
飞行时长 = clamp(米制距离 / 速度, 类型最短时长, 类型最长时长)
```

普通传球最终约落在 8.8–12.4 米/秒区间；短传不短于 0.32 秒，长传不长于 1.62 秒，空接为 0.48–1.85 秒。这个区间是兼顾球场比例、手机可读性和防守反应的玩法校准，不冒充适用于所有传球方式的唯一实测常数。传球类型、压力、距离与比赛环境都会影响实际表现：<https://pmc.ncbi.nlm.nih.gov/articles/PMC7052720/>。

投篮按近筐、中投、三分、扣篮和空接设置不同的解析飞行时长与最高点；篮圈目标高度固定为 3.05 米。投失后的前沿、后沿、侧沿、板筐和空气球会产生不同的确定性落点与反弹距离，远投增加长篮板权重。碰撞结果是经过调参的统计近似，不是柔性篮球、篮圈和篮板的实时刚体求解。

触圈后的反弹创建 `RIM_REBOUND`，未触圈的活球创建 `LOOSE_BALL`。十名球员按同一公式争抢：落点距离和预计到达时间优先，再读取正确的进攻/防守篮板、卡位位置、力量、弹跳、双手、篮球智商、速度与加速度；过晚到达者没有“隔空抢板”概率。当前版本直接解析最终控制者，尚未拆出拍球、连续点抢和二次起跳的独立控制阶段。

防守篮板后，系统比较篮板手自行推进与队友接应。接应评分读取控球、篮球智商、护球、双手、持球速度、传球准确、推进位置与防守压力；出球还读取篮板手的传球准确、视野和篮球智商。若传球线路风险过高则自行推进；选择出球时会显示 `OUTLET` 飞行，并保留被截断的可能。随后由实际持球点在 8 秒内越过中线。

所有飞行与棋子运动每 50 毫秒以内推进一次，并共用 58 毫秒线性 CSS 插值。传球终点在释放时锁定，接球人随后移动不会让篮球逐帧追踪、吸附或延长飞行；球到达固定点后才提交一次接球、出界或失误结果。暂停或页面隐藏会同时冻结比赛时间、球和棋子，恢复时不补算隐藏时间。

## 公平性约束

- 同一状态与种子必须产生同一命中结果、碰撞类型、落点、篮板控制者和后场出球选择。
- 玩家/电脑、主队/客队共用投篮飞行、篮板候选和出球公式；不得添加隐形玩家加成或自动防守篮板加成。
- 视觉轨迹只能表现规则结果，不能因设备帧率、CSS 动画结束事件或截图时机重新改变命中与球权。
- 距离更近、到达更早、相应篮板能力更高或卡位更好时，在其他条件固定下，候选评分不得下降。
- 篮板控制发生前，比分、个人篮板和新球权不能因反弹动画开始而提前结算。

## 验收边界

- 横向 10% 等于 2.865 米，纵向 10% 等于 1.524 米；篮筐高度显示为 3.05 米。
- 同一距离下，提高传球速度属性不得让飞行更慢；同一属性下，长传到达时间必须大于短传，空接必须慢于普通传球。
- 飞行进行中比赛钟和进攻时间按对应规则继续；暂停与页面隐藏时篮球和计时一起冻结。
- 传球释放后接球落点保持不变；移动接球人不得改变终点或让篮球追踪其当前位置，到达事件只能提交一次。
- `BACKCOURT_ADVANCE` 结束的那一帧必须能从持球点坐标证明已经越线。
- 普通防守碰出界时，3 秒保持 3 秒、18 秒保持 18 秒；若同次前场重启明确带有触圈保有球权语义，3 秒才设为 14 秒。
- 触圈进攻篮板控制后为 14 秒，防守篮板控制后为 24 秒；未触圈后原进攻方追回保留剩余时间。
- `SHOT_FLIGHT` 与 `REBOUND` 中篮球必须持续可见，`z` 连续变化且不污染地面 `x/y`；反弹结束后球的位置与实际控制者一致，不能瞬移。
- `FREE_THROW` 中罚球队员必须位于罚球线，其余球员完成对应分位后才释放篮球；整个罚球序列两钟冻结，最后一罚只允许进入底线发球、十人篮板或保留球权的前场重启之一。
