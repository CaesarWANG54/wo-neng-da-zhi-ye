# 挡拆与二次决策规则

## 目标

挡拆不是“按一下获得空位”的奖励按钮，而是一组可被防守破解、也可制造错位的连续决策。动画只展示已经由规则引擎确定的事件，不能在播放过程中重新抽签。

## 按键语义

- 玩家持球：点击“挡拆”呼叫合法且最合适的队友来掩护。
- 玩家无球：点击“挡拆”由玩家为真正持球队友设掩护；持球队友是否使用掩护以及是否回传，读取持球队友的传球、视野和篮球智商。
- 挡拆动作只有单击语义，进行中禁止重复创建第二个掩护。

## 状态链

```text
落位
→ 请求掩护
→ 掩护人接近
→ 防守策略窗口
→ 接触质量结算
→ 防守策略结算
→ 掩护人路线
→ 二次决策
→ 传球 / 投篮 / 突破 / 再掩护 / 重置
```

原型把前六步合并为一次确定性结算并保留事件解释；正式版将它们拆为可播放、可暂停的事件节点。

## 防守策略

| 策略 | 防守结果 | 进攻可读机会 |
|---|---|---|
| 换防 | 两名防守人的对位原子交换 | 大个防持球人时直接投或突破；小个防顺下人时吊传或低位错位 |
| 夹击 | 两人暂时压迫持球人 | 短顺下、弱侧多打少；传球窗口短且失误风险更高 |
| 沉退 + 挤过 | 后卫追身，大个守篮下 | 急停中投、抛投、口袋传球；篮下仍有护框减益 |
| 沉退 + 绕过 | 后卫从掩护下方走 | 三分空间增大，直接突破空间相对减小 |
| 延误后回位 | 大个短暂阻挡持球人再回顺下者 | 高控球与高篮球智商可抢在回位前出球 |

防守成功破解挡拆只会消除初始优势，不自动产生抢断、失误或回合结束。换防也不等于进攻失败，错位会持续到再次换回或死球。

## 掩护接触与路线

掩护质量是隐藏派生值，不额外占用可购买属性：

```text
掩护质量 = 力量 × 45% + 进攻篮球智商 × 35% + 体能 × 20%
```

接触质量还会减去主防守人的绕掩护、横移和协防智商。低接触质量可能导致掩护落空；高篮球智商掩护人可把失败接触转为提前顺下。

路线先计算真实收益，再由篮球智商决定选择稳定性：

- 顺下：终结、扣篮、速度、接球、禁区开放度、是否小个换防。
- 外弹：三分、中投、外线开放度、沉退幅度、空间占用。
- 短顺下：优先用于夹击后的罚球线接球和四打三。
- 假掩护顺下：防守过早扑出或接触条件不佳时使用。

篮球智商不会直接提高命中率；它降低选错路线、错过空位或在拥堵区域停留的概率。

## 传球分为“看见”和“做到”

目标识别读取传球视野、篮球智商、队友机会价值、线路压力和错位价值。传球执行另行读取传球准确、控球、默契以及防守抢断、压力和线路拥堵。

因此：

- 高篮球智商、低传球：能看见正确目标，但球可能不到位。
- 低篮球智商、高传球：传得准，却可能把球给到次优队友。
- 双击传球只有存在真实空接通道时才触发空接；不可用时明确提示，不降级为普通传球。

## 投篮、突破与实际防守人

### 投篮

三分主要读取当前贴防人的外线防守、横移、距离和挡拆分离度。换防发生后必须读取新防守人，不能缓存原始对位，也不能仅根据“大个”标签自动判为空位。

### 突破

突破分两段：

1. 过第一道防线：控球、持球速度、力量、进攻智商，对比当前防守人的外防、横移、抢断和站位。
2. 篮下终结：终结、近投、力量、弹跳和体能，对比能够实际赶到协防路径的内防、盖帽、协防智商和力量。

只因高盖帽中锋“在场”不能给所有突破全局减益；他必须位于正确区域且来得及到位。协防离开弱侧后，应同步提高弱侧底角或外弹点的开放度。

## 概率原则

属性先归一化，再通过逻辑函数转换为概率，并设置上下限。普通事件保留 5%–95% 的结果区间；传球完成率可使用 40%–99% 区间。难度倍率只生成一次有效属性，不能在挡拆、投篮或终结阶段重复相乘。

必须满足以下单调性：

- 其他条件不变，提高相关进攻属性不能降低成功率。
- 提高实际外防不能提高三分命中率。
- 提高实际内防、盖帽和及时协防不能提高篮下终结率。
- 相同种子、相同状态、相同指令序列必须得到完全相同的事件日志。

## 原型固定情境

教学局初始固定种子会选择 5 号中锋为 1 号持球人掩护，并稳定复现防守换防。换防后生成“内线留在外线”的错位，下一次投篮或突破读取该新对位。界面同时绘制顺下和外弹的战术参考路线，事件日志标记本次实际选择。
