# M6A — 2026 选秀、赛程日历与比赛规则补强

## 目标与边界

本轮在既有比赛玩法不改版的前提下，落地可执行的首年选秀仪式、2026-27 赛程日历、按日模拟、赛季统计奖项、回场违例、连续抢断犯规、球队 Bonus、末节战术犯规、音频删减和战术拥挤修复。

数据口径必须分层：首轮签位与 1200 场已确定赛程来自发布数据；12 月杯赛结果决定的 30 场比赛由游戏内结果产生并标记为 `DYNAMIC_CUP`，不得伪装成已发布的固定对阵。真人逐项能力值仍不在本轮范围内。

## 小任务与验收目标

| 编号 | 小任务 | 可执行验收 |
|---|---|---|
| DRAFT-01 | 导入首轮 1–30 顺位、选队与英文新秀名 | 30 个连续唯一顺位；前三顺序和末位有固定测试；自创球员插入时候选人依次顺延且不改变签位球队 |
| DRAFT-02 | 逐顺位选秀仪式 | 玩家第三顺位时必须先依次看到第一、第二顺位；当前签位、球队简称、英文姓名可见；玩家出现前不能进入日历 |
| CAL-01 | 导入固定赛程 | 源 PDF 哈希一致；1200 个连续比赛 ID；30 队各 80 场且无同队同日重复 |
| CAL-02 | 动态杯赛补齐 | 模拟至杯赛阶段前显示每队 2 场待定；解析后全联盟共新增 30 场且每队恰好 2 场，来源为 `DYNAMIC_CUP` |
| CAL-03 | 玩家日历与按日模拟 | 仅显示玩家球队事件；月份可切换；未来日期点击后出现明确模拟目标；确认后当前日期、战绩、赛果、金币与赛季统计同步更新 |
| CAL-04 | 资料区 | 金币固定在顶栏；日历旁可滚动查看完整 38 项属性；不能显示对手属性 |
| CAL-05 | 联盟后台与奖项 | 所有非玩家比赛自动模拟；比分维持职业篮球合理区间；赛季结束以效率、累计贡献与战绩组合评选，奖项不为空 |
| RULE-01 | 回场违例 | 已建立前场控制后，进攻方最后使球回后场且本方先触球即失误、死球并由对手中线发球；投篮、篮板和无球队控制状态不误判 |
| RULE-02 | 连续抢断与 Bonus | 同一防守回合第 5 次抢断点击必定普通犯规；换球权或改做其他防守选择清零；常规单节第 5 次普通球队犯规触发两次自动罚球 |
| RULE-03 | 战术犯规 | 末节或加时最后约 35 秒、落后 1–8 分的电脑防守方可确定性主动犯规；领先方不触发；处罚复用球队 Bonus 和自动罚球链 |
| AUDIO-01 | 删除球鞋摩擦声 | 源码、清单、public 与构建目录无对应引用/文件；运球环境声和命中入网声仍通过哈希门禁 |
| TACTIC-01 | 防止十人扎堆 | 普通移动保持最小视觉间距；合法掩护接触是唯一例外；路线按位置分层且连续回合不重复完整签名 |
| QA-01 | 全按钮与双设备 | 所有启用按钮有可见状态变化；iPhone 与 Pixel 横屏无裁切；控制台无错误；核心测试、浏览器测试、生产构建和内容门禁通过 |

## 实施顺序

1. 锁定外部数据事实、哈希和运行时数据结构。
2. 完成纯逻辑与不变量测试，再接选秀和日历界面。
3. 将新增裁判状态接入唯一时间循环，禁止 React 定时器旁路。
4. 删除音频与优化运动后运行完整回归。
5. 最后才同步到 `D:\我能打职业`，在正式目录重新构建并打开预览。

## 非本轮完成项

- 30 队完整真人名单与 38 项真人属性授权数据包。
- 替补轮换、球队暂停库存、教练挑战、争球和全部罚球线违例。
- 多赛季存档、合同、交易市场与完整季后赛树。

这些项目必须继续在状态矩阵中保持 `PARTIAL` 或 `SPEC_ONLY`，不能因本轮纵向切片通过而宣称整款游戏完成。
