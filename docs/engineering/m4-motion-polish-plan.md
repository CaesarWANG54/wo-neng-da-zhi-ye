版本：0.1（2026-09-01）

## 3. 本轮发现并修掉的漏洞

1. 暂停测试原先只读逻辑坐标，漏掉CSS继续滑行；现改为真实包围盒。
2. 球和棋子使用不同时长导致“脱手”；现共用58 ms。
3. 防守贴身点使用未缩放百分比，号码大面积互盖；现统一横向视觉尺度并软避碰。
4. 运动按球员数组原地更新导致主客反应不对称；现用同一帧快照求目标。
5. 投篮扑防方向反号、挡拆换防追错对象、传球/外弹跨到反侧；均已修正。
6. 任意持球人被拉到控卫点；中锋和大前锋现保留内线创造职责。
7. 死球和快攻清了战术标记却没清路线，且投篮动作还会把路线写回；现由阶段拥有运动并原子换代。
8. 路线图只是装饰线；现与`motion.routes`一一对应。

## 4. 仍需后续完成，不能误报

- 对手先生成出手/突破/传球意图，再由防守键在合法窗口响应。
- 挡拆由真实接触几何触发，而不是1.35秒确定性接触计时；补移动掩护和进攻犯规。
- 快攻用连续时间插值角色推进，并补防守“护筐、停球、找翼、拖车”优先级的三个检查点。
- 双重掩护、手递手等节点依赖，战术被破解后的回落，以及篮板落点/卡位/个人归属。
- 以变换层替代`left/top`的真机GPU优化；当前10枚棋子、20 Hz方案已通过浏览器性能门槛，但仍须安装包真机复测。
